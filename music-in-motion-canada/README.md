# Music in Motion Canada - Preview Site

This is the polished, high-converting preview website for Music in Motion Canada, designed to look modern, premium, and professional while retaining its core function as a Canadian music community hub.

## Key Upgrades Included:
- **Cinematic Canvas Animation:** A lightweight, premium animated guitar string and floating particle background in the hero section.
- **Editorial Typography System:** Implements an elegant Playfair Display & Inter pairing.
- **Authentic Industry Imagery:** Replaced placeholders with real, believable industry faces and premium studio collaboration photography.
- **Conversion Focused:** High-contrast aesthetic with clear, compelling calls to action to drive directory join rates.

## Setup & Deployment
1. This folder (`music-in-motion-canada`) can be deployed directly to Vercel, Netlify, or GitHub Pages.
2. It uses entirely Vanilla HTML/CSS/JS (no build step required).
3. All assets (images, fonts, scripts) are remotely hosted via reliable CDNs (Google Fonts, FontAwesome, Unsplash) or self-contained.

Simply open `index.html` to preview.
